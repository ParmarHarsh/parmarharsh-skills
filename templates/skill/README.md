# Skill template

Copy to `plugins/<name>/`, replace every `NAME` and every capitalized placeholder, and rename the cases after what they test.
A case that inspects a project carries a copy of a folder in `fixtures/` as `project/`, plus the `fixture.sh` and `case.yaml` used in `plugins/release-readiness/evals/go-no-go-prod/`.
See docs/adding-a-skill.md for the rules CI enforces.
